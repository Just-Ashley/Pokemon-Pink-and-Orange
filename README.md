Version number is based off of;
-Major (updates that change physics, add a bunch of content, etc.)
-Minor (updates that fix bugs, add small bits of content, QoL updates, etc.)
-Year of update
-Month of update
-Day of update
-Color Hex code (name of the game you chose to download)

EX: 1.0.2026.10.10.151512001211 would be the release version of Pink (#FFC0CB) if I released it on the 10th of October in 2026.
